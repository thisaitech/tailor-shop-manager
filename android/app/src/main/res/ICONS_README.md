# Android App Icons

Place your app icons in these directories with the following sizes:

## Required Icon Sizes

- `mipmap-mdpi/ic_launcher.png` - 48x48 pixels
- `mipmap-hdpi/ic_launcher.png` - 72x72 pixels
- `mipmap-xhdpi/ic_launcher.png` - 96x96 pixels
- `mipmap-xxhdpi/ic_launcher.png` - 144x144 pixels
- `mipmap-xxxhdpi/ic_launcher.png` - 192x192 pixels

## How to Create Icons

1. **Design your icon:**
   - Use a square canvas (512x512 px recommended)
   - Keep important content within safe area (center 70%)
   - Use your brand colors (currently: #FF6B35)

2. **Generate all sizes:**
   - Use online tools like:
     - https://romannurik.github.io/AndroidAssetStudio/icons-launcher.html
     - https://icon.kitchen
     - https://makeappicon.com
   - Upload your 512x512 icon
   - Download the generated icon pack
   - Replace the files in the mipmap folders

3. **Manual resize (using any image editor):**
   - Export/resize to each required dimension
   - Save as PNG with transparency
   - Replace existing placeholder files

## Current Placeholders

The current icon files are placeholders. Replace them with your actual app icon before publishing.
